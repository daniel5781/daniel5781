# 황색포도상구균 검출확률 예측

**Imbalanced Classification · Feature Engineering · Temporal Validation**

## 문제

비정기적으로 수집된 식품 검사 이력에서 희소한 양성 사례를 활용해 검출 위험도를 추정하고,
검사 우선순위 설정에 도움이 되는 예측을 만드는 프로젝트입니다.

## 접근과 기여

- 과거 검사 이력과 도메인 정보를 활용한 피처 구성.
- 예측 기준일에 이용 가능한 정보만 사용하도록 데이터 누수 점검.
- 불균형 분류 모델 개선 작업과 시간에 따른 검증.
- Average Precision, Recall, 검사 효율을 함께 고려한 결과 비교.

모델 점수만으로 운영 가치를 판단하지 않고, 제한된 검사 자원에서 위험 사례를 얼마나 잘 찾는지 살펴봅니다.
예측 확률은 검사 결과나 안전 판정을 대신하지 않습니다.

원본 검사 자료와 팀 코드는 비공개입니다. 공개 소개에는 실제 검사 기록·기관별 결과·모델 산출물을 포함하지 않습니다.
