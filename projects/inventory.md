# 세븐일레븐 재고 최적화

**PM · 데이터 전처리 · 예측 모델 검증 · 재고 시뮬레이션 · 대시보드 구현**

[모델·검증 코드](https://github.com/daniel5781/7Eleven_MD_Dashboard/tree/main/modeling) · [프로젝트 저장소](https://github.com/daniel5781/7Eleven_MD_Dashboard) · [대시보드 체험](https://daniel5781.github.io/7Eleven_MD_Dashboard/)

## 문제

신상품은 판매 이력이 부족하고 상품·물류센터마다 예약 반응이 다릅니다.
예약량에 고정 배수를 적용하는 발주 기준을 보완하기 위해,
초기 출고량을 예측하고 발주 수량에 따른 재고 부담을 비교한 팀 프로젝트입니다.

타깃은 **출시일부터 4일간의 센터 → 점포 출고량**입니다.
실제 발주량·점포 판매량과 구분하며, 출고 실적을 최종 수요나 최적 발주량으로 단정하지 않습니다.

## 전처리 → 모델 → 검증

- **전처리:** 결정일까지의 예약량·참여 점포, 예약 속도와 집중도, 상품 경제성과 센터 비중을 구성했습니다.
- **모델:** 로컬 v6의 33개 피처와 예약량 대비 출고 배수를 학습하는 LightGBM 5시드 앙상블을 공개용으로 정리했습니다.
- **추가 실험:** 배수·원수량·로그 타깃을 검증 구간에서 결합하는 블렌드를 제공합니다.
- **검증:** 시간순 홀드아웃과 월별 재학습 평가를 사용하고, 예측 시점까지 확정된 라벨만 활용합니다.
- **평가:** WMAPE·MAPE·Bias와 과소·과다 발주 물량을 함께 확인합니다.

공개 패키지는 합성 이벤트 생성부터 피처 생성·학습·추론·모델 저장/복원까지 실행됩니다.
[원본 코드와 공개본의 대응 및 변경점](https://github.com/daniel5781/7Eleven_MD_Dashboard/blob/main/modeling/SOURCE_MAP.md)을 함께 남겼습니다.

## 재고 시나리오와 의사결정

기준 공식, 재산정 공식, 모델 예측과 α 보정 수량을 비교합니다.
공개 시뮬레이션은 일별 재고 수량 보존, 미충족 요청 물량, 잔여 재고와 보유량을 확인하는 예제입니다.
추가 입고·백로그가 없는 가정이며 실제 물류 운영의 모든 제약을 재현하지는 않습니다.

대시보드는 분석 결과를 MD가 검토하고 수량을 조정하는 활용 화면입니다.
현재 웹 데모는 독립된 합성 JSON을 사용하며 Python 모델 실행 결과를 자동 반영하지 않습니다.

포트폴리오에는 [합성 데이터 모델 실행 예제](https://github.com/daniel5781/7Eleven_MD_Dashboard/tree/main/modeling)와
