# 세븐일레븐 재고 최적화

**PM · 데이터 전처리 · 예측 모델 검증 · 재고 시뮬레이션 · 대시보드 구현**

[모델·검증 코드](https://github.com/daniel5781/7Eleven_MD_Dashboard/tree/main/modeling) · [프로젝트 저장소](https://github.com/daniel5781/7Eleven_MD_Dashboard) · [대시보드 체험](https://daniel5781.github.io/7Eleven_MD_Dashboard/)

## 문제와 결과물

신상품은 판매 이력이 부족하고 상품·물류센터마다 예약 반응이 다릅니다.
예약량에 고정 배수를 적용하는 발주 기준을 보완하기 위해 초기 출고량을 예측하고,
발주 수량에 따른 재고 부담을 비교한 팀 프로젝트입니다.

팀 결과물은 예측 모델, 재고 시나리오 분석과 MD 검토 대시보드입니다.
개인 공개본에서는 팀 코드의 핵심 방법을 재구성한 **합성 데이터 모델 예제와 별도의 웹 데모**를 제공합니다.

## 1. 예측 모델 — 결정일까지의 정보로 초기 출고량 추정

타깃은 **출시일부터 4일간의 센터 → 점포 출고량**입니다.
실제 발주량·점포 판매량과 구분하며, 출고 실적을 최종 수요나 최적 발주량으로 단정하지 않습니다.

- 결정일까지의 예약량·참여 점포, 예약 속도와 집중도, 상품 경제성, 센터 비중을 피처로 구성했습니다.
- 공개 기본 모델은 로컬 v6의 33개 피처와 예약량 대비 출고 배수를 학습하는 LightGBM 5시드 앙상블입니다.
- 고정 배수 공식, 학습 구간에서 재산정한 공식, 모델 예측을 비교합니다.
- 시간순 홀드아웃과 월별 재학습 평가에서 학습 시점까지 확정된 라벨만 사용합니다. WMAPE·MAPE·Bias를 확인합니다.

배수·원수량·로그 타깃의 블렌드는 추가 실험으로 제공하며 기본 전달 모델과 구분합니다.
합성 이벤트 생성부터 피처 생성·학습·추론·저장/복원의 실행 방법과
[원본 코드와의 대응·변경점](https://github.com/daniel5781/7Eleven_MD_Dashboard/blob/main/modeling/SOURCE_MAP.md)을 공개했습니다.

## 2. 재고·발주 검토 — 수량별 부담 비교

기준 공식, 재산정 공식, 모델 예측과 α 보정 수량에 따라 과소·과다 물량과 잔여 재고가 어떻게 달라지는지 비교했습니다.
공개 예제는 일별 수량 보존, 미충족 요청 물량, 잔여 재고·보유량을 계산합니다.
α는 검증 구간의 가정에 따라 선택하는 시나리오 변수로, 기업의 권장 발주 기준을 뜻하지 않습니다.

기본 예제는 추가 입고·백로그 없이 비교하며, 원본 프로젝트의 모든 운영 제약이나 장기 재고 분석을 재현하지 않습니다.
공개본의 실행 점수를 실제 재고 물량·비용 절감 성과로 제시하지 않습니다.

## 3. 대시보드 — MD의 수량 검토 화면

예약 추이와 추천 수량을 확인하고, 수량 조정과 센터별 배분을 검토하는 화면 구현에 참여했습니다.
현재 웹 데모는 **독립된 합성 JSON**을 사용하며 Python 모델 실행 결과를 자동 반영하지 않습니다.

## 공개 범위와 출처

학습·검증 예제와 화면 수치는 모두 합성 데이터 기반입니다.
기업 원자료, 기존 학습 가중치·실제 예측표, 내부 발표 자료와 원본 Git 이력은 포함하지 않습니다.
