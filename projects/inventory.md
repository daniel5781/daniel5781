# 세븐일레븐 재고 최적화

**PM · 데이터 전처리 · 예측 모델 검증 · 재고 시뮬레이션 · 대시보드 구현**

[공개 데모](https://daniel5781.github.io/7Eleven_MD_Dashboard/) · [공개 코드](https://github.com/daniel5781/7Eleven_MD_Dashboard) · [팀 원본](https://github.com/Geonhohoho/7Eleven_MD_Dashboard)

## 문제

신상품은 판매 이력이 부족하고, 상품과 물류센터마다 예약 수요와 재고 소진 속도가 다릅니다.
일률적인 발주 기준을 보완하고 예측 결과를 MD의 실제 수량 검토로 연결하는 팀 프로젝트입니다.

## 개인 기여

| 역할 | 담당 범위 |
| --- | --- |
| PM | 프로젝트 진행 관리 |
| 데이터 전처리 | 분석·모델 검증에 사용하는 데이터 준비 |
| 예측 모델 검증 | 초도발주 예측 결과와 검증 조건 점검 |
| 재고 시뮬레이션 | 재고 운영 기준과 결과 비교 |
| 대시보드 구현 | 분석 결과를 발주 검토 화면으로 연결하는 구현 참여 |

## 결과물

예약 추이와 유사상품 확인 → 추천량 검토 → 박스·EA 환산 → 센터별 배분 → 수량 조정·확정의 흐름을 제공합니다.
실제 발주, 센터 출고, 점포 판매를 구분하고, 예측 정확도와 운영 개선 효과를 각각 평가하는 관점을 담았습니다.

공개본은 팀 최종 대시보드를 바탕으로 만든 **합성 데이터 데모**입니다.
실제 기업 데이터, 학습 가중치와 원본 Git 이력은 포함하지 않습니다.
모든 화면 수치는 예시이며 비용 절감 실적이나 실제 모델 성능으로 제시하지 않습니다.
