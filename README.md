## How I Work

**문제 정의 → 데이터 전처리 → 검증 → 의사결정 연결**

- 예측 시점에 알 수 있는 정보만 사용하고 시간에 따른 데이터 누수를 점검합니다.
- 모델 점수와 운영 의사결정 지표를 구분해 평가합니다.
- 채택한 실험뿐 아니라 효과가 없었던 실험과 재현 조건도 기록합니다.
