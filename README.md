About Me
데이터를 분석하는 데서 그치지 않고, 현실의 문제를 예측과 의사결정 문제로 구체화하는 과정에 관심이 있습니다.

데이터 사이언스를 공부하며 산업 데이터 분석, 머신러닝 모델링, 분석 결과의 실무 활용을 중심으로 프로젝트를 수행하고 있습니다.

특히 다음과 같은 질문에 집중합니다.
- 어떤 문제를 예측해야 실제 의사결정에 도움이 되는가?
- 제한된 데이터에서 신뢰할 수 있는 검증 체계를 어떻게 설계할 것인가?
- 모델의 예측을 현장에서 활용할 수 있는 판단 기준으로 어떻게 연결할 것인가?
